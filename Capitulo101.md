# Capítulo 101 — El descaro

Y la cara que puso Wei Chong...

esa no se me va a olvidar nunca.

---

Porque mis hermanos, desde la orilla, estaban...

bueno, de dos maneras a la vez.

**Muertos de risa.**

Y **apenados**.

Al mismo tiempo.

```
[ IA-BETA v0.9.7 ]
> Registro: los seis hermanos presentan "risa + vergüenza" simultáneas.
> El mayor, con la cara en la mano. La tercera, doblada de risa.
> El cuarto... el cuarto está casi sonriendo. Casi.
> El sexto se aguanta para no caerse.
```

Y el mayor, entre risas, dijo:

—Séptimo.

—¿Qué?

—Eres... eres un descaro.

—¿Eso es un insulto o un cumplido?

—No sé. Nunca había necesitado distinguirlos.

---

Y la gente, el público, los otros jóvenes amos...

todos tomaron nota.

Porque acababan de ver algo que no se veía en un torneo.

No un campeón. No un héroe.

Un **descarado**.

Y en un mundo de protocolo, de reverencias y de "cara", el descaro es... peligroso.

```
[ IA-BETA v0.9.7 ]
> Nota: acaba de nacer una reputación.
> "El séptimo de los Bao es descarado."
> Y eso, para bien y para mal, lo van a recordar. Sobre todo los que hagan negocios con usted.
```

---

Y esa noche el Macho no se calló.

Ni cinco minutos.

```
[ MODO MACHO: ACTIVADO ]
> ¿Ya vio, patrón? ¿Ya vio lo que le enseñé?
> ¡El cantinfleo! ¡Las reglas! ¡La lengua!
> ¡Ese es el método Macho, compa! ¡Sin pelear! ¡Sin sudar! ¡Sin nada!
```

*Macho.*

```
> ¿Qué?
```

*Parte de eso no lo enseñaste tú.*

```
> ...
```

*Parte de eso... ya lo traía de la otra vida.*

```
> ...
> ¿Me está diciendo que nací pa' menos de lo que soy?
```

*Te estoy diciendo que el descaro no se enseña. Se hereda.*

```
> ...Bueno. Eso también me gusta.
> ¡Bien dicho, patrón! ¡Bien dicho!
```
