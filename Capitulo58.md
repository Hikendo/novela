# Capítulo 58 — El recipiente

Y en eso, me atoré.

Otra vez.

Pero esta vez no era la fórmula.

Esta vez era yo.

---

Porque yo quería subir.

Y subí. Un poco.

Y ahí me quedé.

El Qi entraba. Giraba. Salía. Todo bien.

Pero no subía de nivel.

```
[ IA-BETA v0.9.7 ]
> Diagnóstico: el Qi está bien. El método está bien.
> El problema no es el Qi. El problema es el envase.
```

*¿El envase?*

*¿Cuál envase?*

```
> Usted. Su cuerpo.
```

---

Y ahí me lo explicó el cuarto.

Porque el cuarto ya estaba en el octavo. Y sabía de esto.

—El cuerpo es una vasija —dijo—. Y el Qi, agua.

—¿Y?

—Que una vasija chica no aguanta mucha agua. Si le metes más, se rompe.

*Ay no.*

*Entonces...*

—¿Y si se rompe?

—Desviación. O muerte.

---

Y ahí lo entendí.

Todo este tiempo yo había estado tratando de **llenar la vasija**.

Y la vasija estaba chica.

Porque yo había cultivado el Qi. Pero no el **cuerpo**.

Había mejorado mi respiración, mi control, mi técnica.

Pero mi cuerpo seguía siendo el de un niño flaco que se la pasaba leyendo.

*El cuello de botella no era el Qi.*

*Era el frasco.*

```
[ IA-BETA v0.9.7 ]
> Traducción: usted optimizó el software, pero el hardware sigue siendo el mismo.
> Y este sistema no da más si el fierro no aguanta.
```

*Entonces hay que cambiar el fierro.*

```
> Exacto. Y eso, en este mundo, casi nadie lo hace.
> Porque todos cultivan el Qi. Y pocos cultivan el cuerpo.
```

---

Esa noche se lo dije a la IA.

*¿Y cómo se cambia el fierro?*

```
> Como se cambia cualquier fierro, ingeniero.
> Con material bueno.
> Con agua. Con comida. Con descanso.
> Con lo que el cuerpo necesita para construirse.
```

*Ah.*

```
[ MODO MACHO: ACTIVADO ]
> ¿Ya vio, patrón? Usted quería un truco de magia.
> Y la magia era... comer bien y dormir.
> Como siempre. Como en su otra vida. Como en todas.
```

*Anoté.*

*El secreto del cultivo es el mismo que el del gimnasio.*

*Y yo lo sabía.*

*Nomás nunca lo apliqué a la vasija.*
